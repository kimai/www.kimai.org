Die besten Funktionen für Sie

Kimai bietet eine breite Palette von Funktionen, die sich an den Anforderungen Ihrer Projektzeiterfassung orientieren, sowie Best-Practice-Lösungen, die unseren Kunden die Buchhaltung erleichtern.

Weitere Funktionen über Erweiterungen

Mobil einsetzbar

Das Layout ist vollständig responsiv und für den Desktop und mobilen Einsatz konzipiert. Jeder Benutzer kann die anzuzeigenden Datenspalten konfigurieren, z. B. um horizontales Scrollen auf kleinen Geräten zu verhindern.

Authentifizierung und Sicherheit

Kimai unterstützt externe Identitätsanbieter und Anmeldung via LDAP und SAML über mehrere Provider (wie Google Workspace, Azure AD oder Authentik). Zwei-Faktor-Authentifizierung über TOTP-Tokens ist optional möglich.

Plugins

Kimai wurde mit Fokus auf Erweiterbarkeit entwickelt, so dass Funktionen mit Plugins hinzugefügt werden können. Entwickler, die eigene Plugins für Kimai erstellen, können auf eine umfangreiche API zugreifen.

Mehrere Benutzer

Kimai kann von beliebig vielen Benutzern verwendet werden: Jede Installation unterstützt eine unbegrenzte Anzahl von Benutzern mit unterschiedlichen Rollen (siehe Berechtigungen).

Mehrere Sprachen

Kimai kann in jede Sprache lokalisiert werden und ist bereits in mehr als 30 Sprachen übersetzt.

Teams

Teams teilen Ihre Benutzer in Gruppen ein. Schränken Sie den Zugriff auf Daten ein, indem Sie Ihren Teams Kunden und Projekte zuweisen.

Kunden

Verwalten Sie Ihre Kunden und legen Sie Adresse, Kontakte, Land, Währung, Sichtbarkeit (zur Archivierung) und viele weitere Felder fest.

Projekte

Verwalten Sie Projekte für jeden Kunden mit Auftragsnummer, Budget und Sichtbarkeit (zur Archivierung).

Tätigkeiten

Tätigkeiten werden Zeiteinträgen zugewiesen und können zur Auswertung und Filterung verwendet werden. Tätigkeiten können global sein, keine Duplikate notwendig, wenn mehrere Projekte dieselbe Tätigkeit nutzen.

Rechnungen

Verschiedene Rechnungsvorlagen, Möglichkeiten zur Gruppierung von Einträgen, konfigurierbare Rechnungsnummern und verschiedene Formate wie PDF und DOCX.

Daten-Export

Stundenzettel können in verschiedenen Formaten exportiert werden. Exportierte Datensätze werden gesperrt und vor weiteren Änderungen geschützt.

Ausgaben

Behalten Sie den Überblick über Ihre Ausgaben. Diese Ausgaben können kategorisiert und in Ihre Rechnungen aufgenommen werden. Die Spesen- und Ausgabenverwaltung ist als kostenpflichtiges Plugin verfügbar.

SAML

Benutzer können sich mit SAML anmelden bzw. registrieren und dafür Ihren vorhandenen Identitätsanbieter wie Google Workspace, Authentik oder Azure Active Directory nutzen.

JSON-API

Mit einer umfangreichen JSON-API zum Lesen und Schreiben von Daten, so dass externe Anwendungen mit Ihrem bevorzugten Time-Tracker kommunizieren können.

Zwei-Faktor-Authentifizierung (2FA)

Kimai unterstützt die Zwei-Faktor-Authentifizierung mit TOTP-Tokens: sichern Sie Ihre Benutzerkonten noch heute ab!

Statistiken

Ihr Dashboard zeigt Ihnen mehrere Statistiken über aufgezeichnete Zeiten und die Menge der gesammelten Daten. Und wir können jederzeit weitere Diagramme hinzufügen!

Docker

Wir haben Docker-Images für die Entwicklung und es gibt mehrere Docker-Compose Varianten für den Produktionsbetrieb.

Stechuhr

Wollen Sie verhindern, das Ihre Benutzer manuelle Zeiteinträge erstellen? Wechseln Sie in den Stechuhr-Modus, der nur „Punch-In“- und „Punch-Out“-Aufnahmen zulässt.

Stundensatz-Berechnung

Tarife können basierend auf Stunden- und Festbeträgen berechnet werden, individuell konfigurierbar für Kunden, Projekte, Aktivitäten und jeden Stundenzettel-Datensatz .

LDAP

Verbinden Sie Kimai mit Ihrem Unternehmensverzeichnisserver (LDAP oder Active Directory) und nutzen Sie Ihre vorhandene Authentifizierungsinfrastruktur.

Migration

Daten aus Kimai v1 können für eine nahtlose Migration Ihrer Zeiterfassung importiert werden.

Anzahl laufender Einträge

Sie können beliebig viele Zeiten gleichzeitig aufzeichnen, oder Sie limitieren die Anzahl paralleler Aufzeichnungen auf eine.

AM/PM-Format

Kimai verwendet eine lokalisierte Version des 24-Stunden-Formats. Aber wenn Sie an das AM/PM-Format gewöhnt sind, können Sie das konfigurieren.

Nur Dauer

Wenn Ihre lokalen Gesetze verlangen, dass Sie nur die Dauer anstelle von Start- und Enddatum und Uhrzeit anzeigen, können Sie diesen Modus global aktivieren.

Suche nach Zeiten

Sie können alle Zeiterfassungen nach Benutzer, Kunde, Projekt, Aktivität und Datum filtern.

Berechtigungen

Anpassbare Berechtigungsstruktur über Benutzer-Rollen: z. B. können Benutzer Zeiten erfassen, Teamleiter können Rechnungen drucken und Projekte/Aktivitäten konfigurieren, Administratoren kümmern sich um Benutzer.

Benutzerprofil

Persönliche Statistiken und Benutzereinstellungen für Stundensatz, Kimai-Design, Passwort und Avatar.

Passwort vergessen

Passwort vergessen? Kein Problem, Kimai hat eine Funktion zum Zurücksetzen des Passworts per E-Mail.

Kundenportal

Geben Sie Kunden- und Projektstatistiken sowie Zeiterfassungsbögen über eine geheime, optional passwortgeschützte URL an andere weiter.

Dunkelmodus

Jede App benötigt einen dunklen Modus. Und dieser hilft auch dabei, die Augen am Abend oder in dunklen Umgebungen zu entlasten.

Berichte und Auswertungen

Analyse der erfassten Zeiten anhand von Benutzern, Kunden, Projekten, Aktivitäten, Tags, Zeiträumen und mehr.

Kennt keine Limits

Egal, ob Sie pro Benutzer oder pro Monat bezahlen – SaaS-Software beinhaltet immer Limits. Der Premium-Tarif kennt buchstäblich "keine Limits". Mit anderen Worten: Sie zahlen nur die Anzahl aktiver Benutzer, Sie werden nicht eingeschränkt und es werden keine Gebühren für inaktive Benutzer verlangt. Sie können eine unbegrenzte Anzahl an Benutzern, Kunden, Projekten, Aktivitäten und Stundenzetteln anlegen. Alles in Kombination mit dem Mitarbeiterzeitkonten, Rechnungsdruck und vielen weiteren Funktionen.

Datenschutz kommt zuerst

Ich respektieren Ihre und die Privatsphäre und Daten Ihrer Nutzer. Dies ist nicht einfach nur eine Floskel der Datenschutzbestimmung, so führe ich mein Business. Ich verkaufe keine Daten. Ich befolge die DSGVO und werde jede Frage über involvierte Auftragsdatenverarbeiter beantworten.

Sicherheit in Kimai

Kimai setzt auf bewährte Verfahren im Anwendungsdesign, um typische Angriffsszenarien zu verhindern. Automatisierte Sicherheitskontrollen sind für jede Software-Entwicklung entscheidend, um die Zeit von der Erstellung bis zur Fehlererkennung zu verkürzen. Diese Scans laufen bei jeder Codeänderung, jedes einzelne mal.

Sicherheit der Platform

Software ist nur so sicher, wie das System auf dem es läuft. Ich verfolge einen umfassenden Verteidigungsansatz um die Server- und Netzwerkinfrastruktur zu schützen. Kunden auf der Cloud-Plattform werden auf mehreren Ebenen beschützt.

E-Rechnungen

Erstellen Sie E-Rechnungen, sowohl als XML als auch PDF-A, in den Formaten EN16931, XRechnung 3.0, Zugferd/Factur-X und mit der Syntax CII & UBL

EU Hosting

Europäisch 🇪🇺 und unabhängig – entwickelt in Österreich 🇦🇹 und gehostet in Deutschland 🇩🇪
