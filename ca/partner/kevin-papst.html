Published extensions

Registres de traça d'auditoria Registra canvis detallats/registres d'auditoria per a fulls de temps, clients, projectes i activitats i els mostra en una línia de temps per element. Veure més Client de consola (PHAR) Client de consola multiplataforma per a Kimai Veure més CSS Personalitzat Permet afegir regles CSS personalitzades a través d'una pantalla d'administració. Veure més Contingut personalitzat Creeu contingut personalitzat per a fulls d'estil, "Javascript", un missatge d'avís global i una nova pàgina per renderitzar contingut "Markdown" per a notícies de l'empresa. Veure més Camps personalitzats Creeu camps addicionals amb configuració lliure per a fulls de temps, clients, projectes, activitats i usuaris en diversos formats. Els camps poden ser opcionals o obligatoris i restringits per permisos. Veure més Portal de clients Comparteix estadístiques de clients i projectes i fulls de temps amb qualsevol mitjançant una URL secreta, opcionalment protegida amb contrasenya. Veure més Paquet de deducció de temps Configura activitats com a temps de deducció i desa durades negatives Veure més Gestió de despeses Feu el seguiment de les vostres despeses segons el client i el projecte. Aquestes despeses es poden categoritzar i incloure a les vostres factures. Veure més Fail2Ban per a inici de sessió Un connector compatible amb Fail2Ban, que registra les sol·licituds d'autenticació fallides Veure més Format fixe de dades de factura (per idioma) Permet establir un idioma global per als formats de dades de factura. Veure més Sincronització amb GrandTotal Connector per a GrandTotal, que permet importar fulls de temps de Kimai Veure més Importador (CSV i JSON) Permet importar fitxers CSV a través d'una pantalla d'administració. Veure més Factura electrònica Plus Factures electròniques (EN16931, XRechnung, ZUGFeRD, Factur-X), exportació automàtica de fulls de temps en PDF i més funcions avançades de facturació Veure més Mode quiosc amb suport per a codi de barres, RFID, Web NFC Control d'assistència en un entorn on l'usuari no té accés a Kimai (p. ex., en un magatzem), utilitzant un escàner de codi de barres o RFID per iniciar i aturar els fulls de temps. Veure més Configuració de bloqueig per usuari Estableix el període de bloqueig per usuari a les preferències de l'usuari. Veure més Planificació de tasques Crea tasques, inicia/atura/pausa-les, assigna-les a usuaris i equips i registra els temps per a elles — gestiona les llistes de tasques pendents amb Kimai Veure més Traduccions Canvia tots els elements visibles (etiquetes de formulari, capçaleres de taula, elements de menú…) a la teva instal·lació de Kimai amb les teves pròpies traduccions Veure més Hores laborables, vacances, malaltia, festius Gestió d'empleats: hores de treball i hores extres.
