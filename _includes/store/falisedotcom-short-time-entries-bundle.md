Times and durations can be typed in short form. They are completed as soon as the field is
left, so Kimai's own calculations keep working. This works in the record dialog and on
**Weekly hours**.

| You type | Time field | Duration field |
| -------- | ---------- | -------------- |
| `9`      | 9:00       | 0:09           |
| `945`    | 9:45       | 9:45           |
| `1330`   | 13:30      | 13:30          |
| `10`     |            | 0:10           |
| `90`     |            | 1:30           |

Times also accept `9.45`, `9h45` and `945p`, and follow the user's 12- or 24-hour format.
Every other format Kimai supports is passed on unchanged.

### Permissions

The plugin adds no permissions and needs no configuration.
