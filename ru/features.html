Лучшие функции учета времени для вас

Kimai предоставляет широкий спектр функций, которые строятся вокруг ваших потребностей в учете времени для проектов и решений, соответствующих лучшим практикам, делая бухгалтерию проще.

Дополнительные функции через плагины

Поддержка мобильных устройств

Макет полностью адаптивный, созданный для настольных и мобильных устройств. Каждый пользователь может настроить столбцы данных, которые должны отображаться, например, для избежания горизонтальной прокрутки на небольших устройствах.

Аутентификация и безопасность

Kimai поддерживает внешние поставщики идентификации и вход через LDAP и SAML на нескольких платформах (например, Google Workspace, Azure AD или Authentik). Кроме того, можно включить двухфакторную аутентификацию с использованием TOTP-токенов.

Плагины

Kimai построен с возможностью расширения набора функций с помощью плагинов. Разработчик, который хочет создать плагин для Kimai, может использовать множество точек расширения.

Многопользовательский

Kimai может использоваться любым количеством пользователей: каждая установка поддерживает неограниченное количество пользователей с различными ролями (см. разрешения).

Многоязычность

Kimai может быть переведён на любой язык, и уже переведён более чем на 30 языков.

Команды

Команды объединяют пользователей в логические группы, например отделы. Ограничьте доступ к данным, назначив клиентов и проекты своим командам.

Клиенты

Управляйте своими клиентами и добавляйте адрес, контакты, страну, валюту, видимость (для архивирования) и многие другие поля.

Проекты

Управляйте проектами для каждого клиента с номером заказа, бюджетом и видимостью (для архивирования).

Активности

Активности используются для привязки единицы работы к записям табеля. Управляйте активностями для каждого проекта с номером заказа, бюджетом и видимостью (для архивирования) или создавайте глобальные, чтобы избежать дублирования.

Выставление счетов

Настраиваемые шаблоны счетов, параметры группировки записей, настраиваемые номера счетов и несколько форматов, таких как PDF и DOCX.

Экспорт данных

Данные табеля можно экспортировать и передавать в форматах XLSX, PDF, CSV и HTML. Экспортированные записи можно заблокировать и защитить от дальнейших изменений.

Расходы

Отслеживайте свои расходы по клиентам, проектам и активностям. Эти расходы можно распределять по категориям и включать в счета-фактуры. Обратите внимание: отслеживание расходов доступно только в платном плагине.

SAML

Входите в систему и регистрируйте пользователей с помощью SAML через существующего поставщика идентификации SSO, например Google Workspace, Authentik или Azure Active Directory.

JSON API

Обширный JSON API для чтения и записи данных, чтобы внешние приложения и пользовательские инструменты могли взаимодействовать с Kimai.

Двухфакторная аутентификация (2FA)

Kimai поддерживает двухфакторную аутентификацию с использованием TOTP-токенов: обеспечьте безопасность ваших учетных записей сегодня!

Статистика

Ваша информпанель покажет вам некоторую статистику о записанном времени и о количестве собранных данных. И мы всегда можем добавить другие диаграммы!

Docker

Выпуск включает в себя образ Docker для разработки и отдельную установку Docker-compose для рабочей среды.

Секундомер

Не хотите, чтобы ваши пользователи регистрировали произвольные записи в табеле? Переключитесь в режим секундомера, который позволяет делать только записи «старт» и «стоп».

Расчёт тарифа

Ставки могут рассчитываться на основе почасовых и фиксированных сумм, настраиваться для клиентов, проектов, видов активности и для каждой записи табеля в отдельности.

LDAP

Подключите Kimai к серверу каталогов своей компании (LDAP или Active Directory) и используйте существующую инфраструктуру аутентификации.

Миграция

Данные из Kimai вер. 1 могут быть импортированы для беспрепятственной миграции вашего регистратора времени.

Количество активных записей

Вы можете вести параллельную запись сколько угодно раз, но при этом можно настроить допустимый лимит активных записей до 1.

Формат AM/PM

Kimai использует локализованную версию 24-часового формата. Но если вы привыкли к формату am/pm, можете настроить его.

Только продолжительность

Если местные законы требуют, чтобы вы показывали только длительность вместо времени начала и окончания, вы можете активировать этот режим глобально.

Фильтры табеля

Вы можете фильтровать все записи времени по пользователю, клиенту, проекту, активности и дате.

Разрешения

Гибкая структура прав доступа. Назначайте пользователям различные роли, например, пользователи могут регистрировать время, лидеры команд могут печатать счета и настраивать проекты/активности, администраторы могут настраивать учётные записи пользователей и клиентов.

Профиль пользователя

Личная статистика и настройки почасовой оплаты, темы Kimai, пароля и аватара для каждого пользователя.

Сброс пароля

Забыли пароль? Нет проблем, Kimai позаботился о вас, предоставив возможность сброса пароля по электронной почте.

Портал клиента

Делитесь статистикой по клиентам и проектам, а также табелями с кем угодно, используя секретный URL, при желании защищённый паролем.

Тёмный режим

Потому что каждому приложению нужен тёмный режим, который помогает снизить нагрузку на глаза вечером или в тёмных помещениях.

Отчеты и анализы

Анализ записанного времени по пользователям, клиентам, проектам, активностям, меткам, временным периодам и многому другому.

Не знает ограничений

Ваше SaaS-приложение всегда имеет ограничения? Только не Kimai: здесь нет ограничений. Вы платите только за количество активных пользователей. Я не ограничиваю вас и не беру плату за неактивных пользователей. Вы можете создать неограниченное количество пользователей, клиентов, проектов, активностей, табелей и многого другого.

Конфиденциальность прежде всего

Я уважаю вашу конфиденциальность, конфиденциальность ваших пользователей и их данные. Нет, это не очередное скучное введение в политику конфиденциальности — так я веду этот бизнес. Я не продаю данные. Я соблюдаю GDPR и отвечу на любой вопрос о привлечённых субпроцессорах.

Безопасность в Kimai

Kimai применяет лучшие практики проектирования приложений для предотвращения распространённых атак. Автоматизированные средства контроля безопасности критически важны для любого рабочего процесса разработки программного обеспечения, чтобы сократить время от создания до обнаружения дефекта. Эти сканирования выполняются при каждом изменении кода, каждый раз.

Безопасность на платформе

Программное обеспечение настолько безопасно, насколько безопасна система, на которой оно работает. Я применяю многоуровневый подход к защите серверной и сетевой инфраструктуры. Клиенты на хостинговой платформе защищены множеством уровней защиты.

Электронные счета

Создавайте электронные счета в форматах XML и PDF/A, соответствующие EN 16931, XRechnung 3.0, Zugferd/Factur-X, с использованием синтаксиса CII и UBL
