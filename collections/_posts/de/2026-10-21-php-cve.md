## Update 21. Oktober - 19:30 Uhr

Das Update ist abgeschlossen. Ein großes Dankeschön an das PHP-Team und alle anderen, die an diesem Release beteiligt waren, und vielen Dank für Ihre Geduld an diesem turbulenten Tag.

### Kimai Cloud

Alle Kimai Cloud Systeme wurden innerhalb weniger Minuten nach Veröffentlichung der offiziellen PHP-Releases aktualisiert. 
Sie müssen nichts tun, jede Umgebung läuft bereits auf der gepatchten PHP-Version.

- Die Gegenmaßnahmen, die wir in den letzten 24 Stunden umgesetzt haben, haben uns in eine gute Ausgangslage gebracht. Dadurch konnten wir alle Systeme vor und während des Updates durchgehend in Betrieb lassen. Die meisten der im CVE-Advisory empfohlenen Einstellungen waren auf unserer Infrastruktur bereits aktiv, denn Sicherheit hat für uns seit jeher oberste Priorität.
- Zwischen der [Veröffentlichung der CVEs](https://www.php.net/archive/2026.php#2026-10-21-5) und der Verfügbarkeit der aktualisierten Pakete sind für kurze Zeit einzelne Anfragen fehlgeschlagen. Ursache waren die zusätzlichen, bewusst strengen Sicherheitsmaßnahmen, die wir vorab eingerichtet hatten. Die Fehler verschwanden, sobald die aktualisierten Pakete installiert waren.

### Docker

Es [dauerte einige Stunden](https://github.com/kimai/kimai/pull/6262), bis die relevanten PHP-Basis-Images aktualisiert waren. Sobald sie verfügbar waren, haben wir die aktualisierten Kimai Docker-Images gebaut und veröffentlicht. 
Die aktualisierten Images sind unter den Tags `2.70.1`, `latest`, `apache`, `2` und `stable` verfügbar.

**Stellen Sie sicher, dass Sie einen Tag verwenden, der weiterhin Updates erhält.** Eine Übersicht finden Sie in der Liste der [unterstützten Tags](https://www.kimai.org/documentation/docker.html) in unserer Dokumentation.

Mit dem folgenden Befehl können Sie die PHP-Version Ihres Images prüfen (ersetzen Sie `kimai` durch den Namen des Images, das Sie verwenden):

```bash
docker run kimai php -v
```

Die Ausgabe sollte so aussehen:

```
PHP 8.3.36 (cli) (built: Oct 21 2026 16:06:16) (NTS)
Copyright (c) The PHP Group
Zend Engine v4.3.36, Copyright (c) Zend Technologies
    with Zend OPcache v8.3.36, Copyright (c), by Zend Technologies
```

## Ankündigung 21. Oktober - 10:00 Uhr

### Was ist passiert

Am 20. Oktober 2026 hat das PHP-Sicherheitsteam [ein Notfall-Sicherheitsrelease angekündigt](https://www.php.net/archive/2026.php#2026-10-20-1), das zwei kritische Schwachstellen in PHP selbst behebt, beide mit 9,2 von 10 Punkten bewertet. 
Das Release ist für den 21. Oktober 2026 um 14:00 Uhr UTC geplant. 

Die Schwachstellen liegen **nicht im Code von Kimai**. 
Sie stecken in der PHP-Laufzeitumgebung, daher ist potenziell jede PHP-Anwendung weltweit betroffen. 
Ein Update von Kimai allein behebt das Problem nicht: PHP selbst muss auf jedem Server aktualisiert werden, auf dem es läuft.

### Was wir tun

Wir verfolgen die Lage seit dem Abend des 20. Oktober genau und haben in unserer gesamten Infrastruktur Vorkehrungen getroffen.
Unser Team steht bereit und spielt den offiziellen PHP-Fix ein, sobald er veröffentlicht ist. 
Wir aktualisieren diesen Beitrag, sobald es Neuigkeiten gibt.

### Wichtig für Kimai Cloud Kunden

Sie müssen nichts tun, um den Fix zu erhalten. 
Wir aktualisieren alle Kimai Cloud Server direkt nach Veröffentlichung des PHP-Sicherheitsreleases. 

Im Laufe des Tages kann es zu kurzen Unterbrechungen oder vereinzelten Fehlern kommen, während wir zusätzliche Sicherheitsmaßnahmen umsetzen und die Updates installieren. 
Wir bitten die Unannehmlichkeiten zu entschuldigen. 
Die Sicherheit unserer Plattform hat für uns oberste Priorität, daher können wir diesmal nicht auf ein geplantes Wartungsfenster warten. 

Falls etwas nicht wie erwartet funktioniert, kontaktieren Sie uns unter [{{ site.support_email }}](mailto:{{ site.support_email }}). 

### Selbst gehostetes Kimai mit Docker

Die PHP-Laufzeitumgebung ist Teil unseres Docker-Images. 
Sobald PHP den Fix veröffentlicht, stellen wir aktualisierte Kimai-Images bereit, und Sie können Ihre Installation aktualisieren, indem Sie das neue Image herunterladen. 
Den genauen Image-Tag veröffentlichen wir in <https://github.com/kimai/kimai/pull/6262>, sobald er verfügbar ist.
