Here’s a summary of the most notable changes since the last update.

**Absences**

- You can edit existing absence types: Holiday, Sickness, Time-Off, Other
- You can create new and hide existing absence types
- Absence types let you decide what requires approval, allows overbooking, half-days and more
- New API endpoints to manage absence types
- Highlight "today" in Absence calendar

Watch the new [How-To Video on YouTube](https://youtu.be/WorSyqKa3D0) to learn more about custom absence types.

**Invoices**

- You can search invoice history by invoice number
- Unpaid invoices are highlighted
- E-invoice prefers the customers invoice email over the contact email attribute
- Use consistent currency aware monetary rounding "half-up"

**Improvements**

- Keep the calendar month in the URL on reload
- Faster and memory efficient export preview & statistics
- Importer skips unknown rate settings
