[Easypanel](https://easypanel.io){:target="_blank" .external-link} is a self-hosted Docker deployment platform. It maintains a one-click deployment template for Kimai that wires up the application and MySQL database automatically.

{% include documentation/self-hosting-warning.md %}

## Deploy Kimai

1. [Install Easypanel](https://easypanel.io/docs/installation){:target="_blank" .external-link} on your own server, if you haven't already.
2. Open the [Kimai template page](https://easypanel.io/templates/kimai){:target="_blank" .external-link} and click **Deploy**.
3. Once deployed, Easypanel assigns a domain automatically. Open it to reach the Kimai login page.

The template creates the admin user for you from the credentials you set in the deploy form.
